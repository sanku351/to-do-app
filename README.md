# React Native To-Do List App

A comprehensive to-do list application built with React Native and Firebase. This app allows users to create, manage, and organize their daily tasks with reminders and notifications.

## Features



### Core Features
- ✅ Create, edit, and delete tasks
- ✅ Mark tasks as completed or incomplete
- ✅ View entire to-do list upon opening the app
- ✅ Firebase integration for data persistence across devices
- ✅ User authentication with Firebase Auth

### Bonus Features
- ✅ Task notifications at specified times
- ✅ Task sorting (by date added or scheduled date)
- ✅ Cross-platform support (Android and iOS)
- ✅ Clean, intuitive UI with smooth animations

## Technologies Used

- React Native
- Expo
- Firebase (Authentication & Firestore)
- React Navigation
- Expo Notifications

## Prerequisites

- Node.js (v14 or newer)
- npm or yarn
- Expo CLI (`npm install -g expo-cli`)
- Firebase account
